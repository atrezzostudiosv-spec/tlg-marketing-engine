# TLG Marketing Engine

Aplicación interna de planificación y producción de contenido inmobiliario.

## Objetivo

Entregar un calendario editorial con paquetes de publicación completos, comprobados y listos para su uso en los canales sociales. La publicación externa se mantiene bajo control humano.

## Documentación

- [Blueprint V1.0](docs/BLUEPRINT.md): alcance, arquitectura, reglas de calidad y criterios de aceptación.

## Estado

Fase 01 — Blueprint. No hay aplicación ejecutable ni integraciones configuradas todavía.

## Seguridad

El repositorio contiene únicamente código y documentación técnica. No almacenar credenciales, datos personales, información comercial privada, fotografías sin autorización ni inventarios reales. Utilizar variables de entorno y almacenamiento privado para los datos operativos. Antes de cargar información del negocio, convertir el repositorio a privado y configurar los controles de acceso.

## Principio

Analizar → planificar → producir → verificar → entregar.
