# Biblioteca multimedia — incremento 1

Carga privada por backend autenticado, autorización explícita del operador, formatos JPG/PNG/WebP/MP4 y límite inicial de 6 MB por archivo (carga estándar). Validación de firma básica del tipo, SHA-256 y tamaño; no constituye decodificación completa, análisis antimalware ni revisión visual. El registro exige que exista metadata del objeto en Storage; la vista previa recupera bytes vía servidor, verifica hash, tamaño y firma y responde sin caché. Los archivos no se publican ni se almacenan en Git. Puede quedar un objeto huérfano si falla el registro después de subir: reconciliar antes del piloto. Para videos grandes, implementar carga resumible antes de uso real.

La biblioteca clasifica por propiedad, derechos, staging y tipo de espacio declarado. El planner prioriza exterior y diversidad de espacios; no analiza fotografías mediante IA ni certifica su contenido. La selección manual ordenada exige 2–5 imágenes para carrusel o un archivo para otros formatos; rechaza otra propiedad, medios no aprobados, duplicados y revisiones obsoletas. Un cambio borra las variantes actuales, mantiene historial y obliga a regenerar. No cambia Meta ni habilita exportación. La demo solo presenta fichas ficticias de medios sin binarios. Supabase real, revocación de derechos, reconciliación, carga múltiple/grande y exportación siguen pendientes. API de Storage: https://supabase.com/docs/guides/storage/uploads/standard-uploads y https://supabase.com/docs/guides/storage/serving/downloads.
